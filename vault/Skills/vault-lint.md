# Skill: Vault Lint

Run the content checks and fix what they find, with consent.

- `canon-lint` checks people notes: duplicate people, shared identifiers, wrong-country
  phones. Fix path for duplicates: merge through canon-propose, every nickname into the surviving note's `aliases:`.
- Broken wiki-links and orphan notes: list them, propose a fix per item, apply on approval.
- Never mass-edit. One finding, one shown fix, one confirmation.
