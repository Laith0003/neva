# Skill: Food Log

Append to the monthly file in Food/ using the documented line format. Lookups: use the
Open Food Facts API (no key needed) for packaged items; estimate whole foods honestly and
say it is an estimate. Totals on request or at the configured check-in times. If no targets
are configured, track without judging. Never lecture; one nudge per day maximum, and the
owner's annoyance line from setup is law.
