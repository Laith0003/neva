# Skill: New Project

Scaffold a project note in 01 Projects through the canon gate.

Interview (max 5 questions, one at a time): what is it, done-means-what, deadline if any,
who else is involved (one-person-one-note applies to any names given), which existing goal
it serves. Then create the note with frontmatter (status: active, date), link it from
GOALS.md, and offer a weekly check-in on it.
