# For the AI reading this folder

This is an installable personal-agent template. When the person says "start", "install",
"set me up", or anything similar: follow START.md exactly. It is your step-by-step script
for a interview-first setup: a real conversation about their life and goals, with the technical install happening quietly behind their answers.

If they ask what this is before starting, answer from README.md. Never run install steps
without being asked to start, and never print credentials into chat.
